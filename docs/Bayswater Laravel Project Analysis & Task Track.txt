📊 **Bayswater Laravel Project Analysis & Task Track**

================================================================================

## **Project Overview**

**Purpose**: This is a **Language School Fee Calculator System** for Bayswater Education, designed to calculate course fees, accommodation costs, and additional services for international students.

**Main Features**:
- Multi-region language school management
- Course and accommodation pricing calculator
- PDF quotation generation
- Admin panel for managing schools, courses, prices, and discounts
- Agent access for fee calculations
- Multi-currency support
- Airport transfer calculations
- Discount rule engine

**Technologies Used**:
- **Backend**: Laravel 12 (PHP 8.2+)
- **Frontend**: Blade templates, TailwindCSS, Alpine.js
- **Database**: SQLite (development), supports MySQL/PostgreSQL
- **Build Tools**: Vite, PostCSS
- **PDF Generation**: DomPDF
- **Additional**: Puppeteer for advanced PDF features

================================================================================

### **Strengths**
✅ Well-structured Laravel application with proper MVC architecture

✅ Good use of Eloquent relationships
