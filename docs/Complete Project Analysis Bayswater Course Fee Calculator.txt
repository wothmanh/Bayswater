# Complete Project Analysis: Bayswater Course Fee Calculator
I have thoroughly analyzed the Laravel-based course fee calculator system. Here's my comprehensive understanding:

## Project Overview
This is a sophisticated web application for Bayswater Education that calculates course fees, accommodation costs, and generates quotations for international students. The system handles complex business rules including seasonal supplements, discounts, Christmas breaks, and role-based access control.

## Technology Stack
- Framework : Laravel 12.0 (PHP 8.2+)
- Authentication : Laravel Breeze
- PDF Generation : DomPDF (barryvdh/laravel-dompdf)
- Frontend : Blade templates with Tailwind CSS
- Database : SQLite (configurable to MySQL/PostgreSQL)
- Styling : Custom Bayswater brand colors and Poppins font
## User Roles & Access Control
### Admin Users
- Full system access including data management
- Can manage: Countries, Cities, Schools, Courses, Accommodations, Discounts, Users, Settings
- Access to admin quotation calculator at /admin/quotations/create
- User management capabilities
### Agent Users
- Limited access to fee calculator only
- Access to agent calculator at /calculator
- Cannot access administrative functions
- Same calculation features as admin but restricted interface
### Access Control Implementation
- IsAdmin middleware checks Auth::user()->isAdmin()
- User model has role field ('admin' or 'agent')
- Role-based navigation in sidebar
- Route protection via middleware groups
## Core Business Logic & Fee Calculation
### FeeCalculatorService - The Heart of the System
The FeeCalculatorService handles all fee calculations with these components:
 Course Fees
- Tuition : Based on pricing type ('per_week' or 'fixed_schedule')
- Summer Supplement : Applied if course overlaps with school's summer period (unless waived by duration)
- Course Duration : Calculated in Monday-to-Friday weeks
- Christmas Break Handling : Extends course duration if overlap detected School Fees
- Registration Fee : Mandatory unless waived by discount
- Bank Charges : Processing fees
- Books Fee : Prorated based on books_weeks setting
- Courier Fee : Optional for visa documents (I-20)
- Under-18 Fees : Guardianship (per week) or Custodianship (one-time) for students under 18 Accommodation Costs
- Base Price : Per week pricing with duration-based tiers
- Placement Fee : Unless waived
- Summer Supplement : If accommodation overlaps summer period
- Christmas Supplement : Additional cost during Christmas period
- Christmas Extra Weeks : Additional accommodation during school breaks Addons & Transfers
- Addons : 'per_week' or 'one_time' pricing
- Airport Transfers : Arrival and departure options
- School-specific : Only available airports linked to selected school
### Complex Date Calculations
- Monday-to-Friday Logic : All durations calculated in business weeks
- Christmas Break Detection : Automatically detects course/accommodation overlap with school Christmas periods
- Course Extension : Automatically extends course end date to account for Christmas breaks
- Accommodation Alignment : Ensures accommodation dates align with course requirements
### Discount System
Sophisticated discount engine with:
 Discount Types
- Percentage : % off specified component
- Fixed Amount : Flat reduction
- Fee Waiver : Completely removes specific fees
- Fixed Amount Per Week : Weekly discounts for accommodation Discount Conditions
- School/Region/Country : Geographic restrictions
- Course/Accommodation : Specific product requirements
- Duration : Minimum/maximum weeks requirements
- Date Conditions : Based on booking date or start date
- Student Age/Nationality : Demographic targeting Application Rules
- Priority System : Non-combinable discounts applied by priority
- Combinable Discounts : Can stack with other discounts
- Category Separation : Prevents multiple discounts on same cost category
